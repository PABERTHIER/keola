# Keola Content Skill

## Source language

French.
Add or update the matching English and Japanese locale entries in the same change.

## Voice

Warm, direct, friendly and lightly playful.

## Good copy

Short.

Specific.

Human.

Useful.

## Avoid

- generic marketing claims
- artificial hype
- long paragraphs above the fold
- excessive emojis
- forced lore references
- infantilizing language

## Headlines

Use personality in headings, clarity in supporting copy.

## CTA verbs

Prefer:

- Regarder
- Découvrir
- Rejoindre
- Voir
- Explorer
- Soutenir
- Suivre

## Social copy

Explain what a platform is for when it is not obvious.

Example:

- Twitch — lives
- YouTube — videos
- Discord — community
- Instagram — illustrations / photos

## Conservation

Keep conservation messaging sincere and concise.

The objective is to connect visitors with the cause, not guilt them.

## Empty states

Be playful but explicit.

Example:
“Les petits esprits préparent encore cette page.”

Then explain what the user can do next.

## Accessibility copy

Link labels should describe the destination/action.

Avoid “Clique ici”.
