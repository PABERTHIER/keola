# Keola — Content Direction

## 1. Voice

Recommended voice:

- warm
- friendly
- direct
- lightly playful
- community-oriented
- occasionally whimsical

The site should feel like Keola is welcoming someone into her world.

## 2. Language

French is the source language for the current website.
New or changed copy must also be supplied in English and Japanese in the matching locale files.

UI labels should remain concise.

## 3. Copy pattern

Prefer:

> short sentence + useful detail + clear action

Avoid:

- corporate marketing jargon
- exaggerated hype
- generic influencer language
- walls of text

## 4. Headline style

Good:

- “Bienvenue chez les Petits Esprits”
- “Le prochain rendez-vous”
- “Un petit coin pour les pandas roux”
- “Entre deux streams, on explore…”

Use poetic wording selectively.

## 5. Conservation messaging

The conservation mission should feel genuine, not like an advertisement.

Structure:

1. why Keola cares
2. what the organization does
3. what visitors can do
4. link to learn more / support

## 6. Community language

Community should feel like a place, not a mailing list.

Useful vocabulary:

- refuge
- petit esprit
- temple
- forêt
- rendez-vous
- aventure
- partager

Do not overuse lore vocabulary.

## 7. Sponsorships

Sponsor blocks should remain visually coherent but clearly recognizable as partnerships.

Use:

- compact logo
- short explanation
- benefit/code if relevant
- external link

Do not let sponsorships dominate the hero.

## 8. Credits

Credits should be treated as part of the creator ecosystem.

Make contributors discoverable and appreciated without turning the page into a dense wall of names.
